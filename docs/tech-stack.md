# Tech stack

React 19; TypeScript 5.8; Vite 6; custom responsive CSS; Lucide React icons; decimal.js; Python 3.11 standard-library Decimal, Fraction, unittest, CSV, JSON, hashlib; ESLint; GitHub Actions configuration; OpenAI Sites static hosting. Demo: Microsoft Neerja Expressive Neural synthetic narration via edge-tts 7.2.8, FFmpeg via imageio-ffmpeg 0.6.0, H.264/AAC, SRT and burned-in captions.

No Lovable, Emergent, Streamlit, or Render. No production Python package is required. Google Fonts loads DM Sans and Manrope with system fallbacks. The browser computes editable scenarios locally; published reports are static artifacts generated from the official data.
